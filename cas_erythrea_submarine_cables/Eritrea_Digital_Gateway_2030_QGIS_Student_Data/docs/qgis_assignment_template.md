# QGIS Assignment Template

## Research question

Which connectivity scenario should Eritrea prioritize if the objective is to convert internet access into durable economic-development capability rather than merely into short-term connectivity?

## Required map outputs

Map 1 should show regional context, existing schematic cable corridors, Eritrean cities, and regional landing hubs. Map 2 should isolate Scenario 1 and overlay synthetic risk zones. Map 3 should isolate Scenario 2 and show the 50 km satellite buffers. Map 4 should isolate Scenario 3 and compare the Massawa and Assab landing alternatives with the domestic backbone.

## Decision memo

The memo should be no more than one page. It should identify the recommended scenario, the governance model, the strongest objection to the recommendation, and the data limitation that most affects confidence in the conclusion.
